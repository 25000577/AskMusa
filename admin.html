Step-by-step setup guide

1

Create a PayFast merchant account

Go to payfast.co.za/registration and sign up as a merchant. You'll need your South African ID and bank account details. Approval usually takes 1–2 business days.

2

Get your Merchant ID and Merchant Key

Once approved, log in to your PayFast dashboard → Settings → Integration. Copy your Merchant ID and Merchant Key. Also set a Passphrase (a secret you choose) in the same screen.

3

Add your credentials to the .env file

Open backend/.env (copy from .env.example if it doesn't exist) and fill in:

PAYFAST_MERCHANT_ID=10000100 PAYFAST_MERCHANT_KEY=46f0cd694581a PAYFAST_PASSPHRASE=yourSecretPhrase PAYFAST_SANDBOX=false # change to false for live payments APP_URL=https://yourdomain.co.za # must be a public URL PayFast can reach
4

Make your server publicly reachable (for ITN webhook)

PayFast sends a payment confirmation to POST /api/payfast/notify. This URL must be publicly accessible — it can't be localhost. Options:

  • Deploy to Render / Railway / Fly.io — free tier works. Set APP_URL to your deployed URL.
  • Tunnel with ngrok for local testing: ngrok http 3001 and set APP_URL to the ngrok URL.
5

Test with the PayFast Sandbox

Keep PAYFAST_SANDBOX=true while testing. Use the sandbox test card on sandbox.payfast.co.za. Learners will pay real money only when PAYFAST_SANDBOX=false.

6

Set up SMTP for email verification (optional but recommended)

Without SMTP, verification links are printed to the terminal. To send real emails, add to .env:

SMTP_HOST=smtp.gmail.com SMTP_PORT=587 SMTP_USER=you@gmail.com SMTP_PASS=your_app_password # Gmail App Password, not your login password SMTP_FROM=you@gmail.com

For Gmail: enable 2FA → Google Account → Security → App Passwords. Or use Resend (free 3,000 emails/month, simple API).

7

Restart the backend and you're live

After editing .env: Ctrl+C to stop the server, then npm start again. Learners who click Plus or Pro will be redirected to PayFast, pay, and their account will upgrade automatically when PayFast sends the ITN.
